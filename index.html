Dott, AI Automation Specialist

Cleared a 30,000+ fine backlog with a Gemini-to-NetSuite pipeline

City fines arrived as PDFs in different formats and languages, and Finance created each NetSuite bill by hand. I built the pipeline that now reads, checks and posts them.

96%
extraction accuracy with Gemini
8 h/week
saved for the finance team
23% → 2%
late-payment penalties, 2025 to 2026
  • n8n
  • Gemini
  • PostgreSQL
  • BigQuery
  • NetSuite REST API
  • OAuth 1.0
Problem
Every country, and often every city, uses its own layout, language and payment reference. Manual keying could not keep pace, so a backlog built up and late payments drew penalties.
Approach
The pipeline extracts each fine with country-specific AI prompts, then validates and deduplicates the data in BigQuery and PostgreSQL. Each fine passes an approval step and posts as its own vendor bill, so every city payment reference reconciles cleanly.
Tools
Self-hosted n8n on Docker, Gemini for extraction, and PostgreSQL as the central store, mirrored to BigQuery for reporting. For NetSuite's REST API, I wrote a custom OAuth 1.0 TBA (HMAC-SHA256) signer, because n8n's built-in credential could not handle it.
Result
Manual bill creation is gone: approved fines post to NetSuite without data entry, and Finance reviews exceptions instead of typing invoices. The pipeline started in Germany and now also runs for Finland and Norway.
My role
I owned it from start to finish. I gathered requirements with Finance and local operations, designed the pipeline, built the ERP integration and scoped each new country's rollout.

Dott, AI Automation Specialist

Cut press-inbox response time from 1 week to 1 day with GenAI triage

The press inbox was flooded with collaboration requests. I built a GenAI assistant that ignores the noise and drafts accurate, localized replies to real press inquiries for the team to review.

  • n8n
  • Gemini
  • Gmail
  • Google Docs
  • Prompt engineering
Problem
Real press inquiries were buried among collaboration pitches, and every answer had to match official company positions. Replies often took a week.
Approach
The workflow takes only the first message in a thread and passes it to a Gemini agent. For collaboration requests the agent returns an empty output, and the workflow stops. For real inquiries, it pulls answers from Dott and German TIER Q&A documents and saves an HTML reply as a Gmail draft in the thread.
Tools
n8n as the automation platform, Gmail for the trigger and drafts, Gemini as the language model, and Google Docs as the Q&A knowledge source.
Result
The assistant acts as a first-pass filter. It skips follow-ups and collaboration spam. Every real inquiry has a concise, localized draft waiting in its thread when the team opens it.
My role
I architected the workflow end to end: the Gmail, Google Docs and Gemini integrations, the classification prompt and the filtering logic.
