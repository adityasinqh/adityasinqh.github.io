    Dott, AI Automation Specialist

    Automating traffic fine processing across European markets

    City fines arrived as PDFs in different formats and languages, and Finance keyed each one into NetSuite by hand. I replaced that with a pipeline that cleared a 30,000+ document backlog.

    • n8n
    • Gemini
    • PostgreSQL
    • BigQuery
    • NetSuite REST API
    Problem
    Traffic and parking fines from cities across Europe arrived as PDFs in different formats and languages. Finance had to key each one into NetSuite by hand, leaving a backlog of 30,000+ documents and frequent late-payment penalties.
    Approach
    A pipeline that extracts each fine with country-specific AI prompts, validates and deduplicates the data, routes it through an approval step, and posts one vendor bill per fine so every city payment reference reconciles cleanly.
    Tools
    Self-hosted n8n on Docker, Gemini for document extraction, PostgreSQL as the central store (mirrored to BigQuery for reporting), and NetSuite's REST API with a custom OAuth 1.0 TBA (HMAC-SHA256) signer I wrote, because n8n's built-in credential could not handle it.
    Result
    The backlog was cleared with no manual data entry at 96% extraction accuracy. Late-payment penalties in Germany fell from 23% to 2%, and the pipeline expanded from Germany to Finland and Norway.
    My role
    I owned it end to end, from gathering requirements with Finance and local operations to designing the pipeline, building the ERP integration, and scoping each new country's rollout.

    Dott, AI Automation Specialist

    Automating PR inbox triage and localized AI response drafting

    The press inbox was flooded with collaboration requests. I built an AI assistant that ignores the noise and drafts accurate, localized replies to real press inquiries for the team to review.

    • n8n
    • Gemini
    • Gmail
    • Google Docs
    • Prompt design
    Problem
    The PR team receives a high volume of emails to the company press inbox, including many irrelevant collaboration requests. They needed a way to automatically ignore collaboration emails while quickly generating accurate, localized responses to legitimate press inquiries using official company knowledge.
    Approach
    A workflow that filters for the first message in a thread and uses a Gemini AI agent to analyze the email text and subject. The agent is prompted to return an empty output for collaboration requests, while valid inquiries trigger knowledge retrieval from Dott and German TIER Q&A documents to draft an HTML response of under 150 words in the original language. Valid outputs are then routed to create a Gmail draft for human review.
    Tools
    n8n as the core automation platform, Gmail for triggering and creating draft replies, Google Gemini for AI language modeling, and Google Docs for retrieving internal Q&A context.
    Result
    The automation acts as an intelligent first-pass filter, ignoring follow-up emails and collaboration spam while preparing concise, accurate and localized drafts for valid press inquiries directly in the Gmail thread. Response time for the press inbox fell from one week to one day.
    My role
    I architected the workflow end to end: configuring the Gmail, Google Docs and Gemini integrations, engineering the prompt instructions that handle collaboration emails and language matching, and designing the filtering logic so it triggers only on the first email of a thread.
